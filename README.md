# SOULeMASH

SOULeMESH — это Telegram-бот нового поколения для знакомств и общения между студентами и старшеклассниками.
Название — это игра слов:

казахское «сөйлемеш» (не говори)

и английское «Soul Mesh» (сеть душ).

Главная идея — не свайпать внешность, а подключиться душой.

🔮 В отличие от обычных ботов, SOULeMESH:

обеспечивает анонимность и безопасность

подбирает собеседников по интересам и психотипу

считает сообщения и завершённые диалоги

скоро будет использовать ИИ для подбора по вайбу, анализа беседы и рекомендаций

Проект полностью реализован на Python с использованием:

aiogram 3.x (Telegram Bot Framework)

PostgreSQL + asyncpg (асинхронная база данных)

планируется подключение OpenAI GPT / HuggingFace
